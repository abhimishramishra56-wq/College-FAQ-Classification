Task 1 – AI Problem Design

1. Project Title

College FAQ Classification System Using AI/NLP

2. Problem Statement

Students often face difficulty finding information about college exams, fees, results, timetable and admissions. This project aims to classify student questions into different categories using Artificial Intelligence and Natural Language Processing.

3. Target Users

- College Students
- Teachers
- College Administration Staff

4. AI Use Case

This project uses Text Classification to identify the category of a student's question.

5. Data Source

A sample dataset of 50 college-related questions will be created manually.

6. Categories

1. Exams
2. Fees
3. Results
4. Timetable
5. Admissions

7. Constraints

- Limited dataset of 50 questions.
- Questions will be in English.
- Spelling mistakes may affect predictions.
- The system only classifies questions.

8. Success Criteria

The initial target is at least 80% classification accuracy on unseen test questions.

9. Evaluation Approach

The model will be evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

10. Expected Outcome

The system will help organize student questions into different categories and make college information management easier.

11. Conclusion

This project demonstrates how Artificial Intelligence and NLP can be used to solve a practical college-related problem.
